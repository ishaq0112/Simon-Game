# Simon Game

An interactive memory-based game built using HTML, CSS, and JavaScript.  
The objective is to repeat an increasingly complex sequence of colors generated by the game.

## How It Works

- The game generates a random color sequence.
- The player must repeat the sequence by clicking the buttons.
- Each correct attempt increases the level and adds a new step.
- A wrong input ends the game.


## Features

-  Interactive UI with colorful buttons
-  Sound effects for each button
-  Increasing difficulty with each level
-  Game Over detection
-  Restart functionality
-  Smooth animations and transitions



##  Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
